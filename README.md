# K-Pop Gummy Bear Radio 🐻🎶

Интерактивный Android-плеер для прослушивания K-pop радиостанций с анимированным мармеладным мишкой.

## Что в этой версии (MVP 0.1)

- 🎀 **Желе-мишка** с зонами касания (ушки, лапки, животик, ножки)
- 📻 **2 K-pop станции**: LISTEN.moe K-POP и Big B Radio KPOP
- 🔊 Управление громкостью (ушки ±5%)
- ⏭️ Переключение станций (лапки)
- ⏯️ Play/Pause (животик)
- 📝 Бегущая строка с названием станции
- 🔔 Фоновое воспроизведение с уведомлением

## Что планируется

- Локальные аудиофайлы (ножки — переключение источника)
- Избранное в Room DB (ножки — добавление)
- Поиск обложек альбомов (iTunes/Last.fm/Spotify API)
- Каталог RadioBrowser (дополнительные станции)
- ICY-метаданные треков
- Адаптивная неон-подсветка по доминирующему цвету обложки

## Управление

| Зона | Действие |
|------|----------|
| Левое ушко | Громкость −5% |
| Правое ушко | Громкость +5% |
| Левая лапка | Предыдущая станция |
| Правая лапка | Следующая станция |
| Животик | Play / Pause |
| Левая ножка | *Переключение источника* (в разработке) |
| Правая ножка | *Избранное* (в разработке) |

## Сборка

### Требования
- JDK 17
- Android SDK (compileSdk 35, build-tools 35.0.0)
- Gradle 8.9

### Локальная сборка
```bash
./gradlew :app:assembleDebug
```

### GitHub Actions
Загрузка кода в ветку `main` автоматически запускает сборку debug APK.
Результат: **Actions → Build Android APK → Artifacts → KPop-Gummy-Radio-debug**

## Технологии
- Kotlin 2.0.21 + Jetpack Compose
- AndroidX Media3 (ExoPlayer + MediaSession)
- minSdk 26 (Android 8.0+)
